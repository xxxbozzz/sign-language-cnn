# Dataset setup

This project uses the Sign Language MNIST dataset from Kaggle:

https://www.kaggle.com/datasets/datamunge/sign-language-mnist

After downloading the dataset, place these two files in this folder:

```text
data/sign_mnist_train.csv
data/sign_mnist_test.csv
```

The CSV files are not committed to the public repository. They are relatively large, and it is better for users to get the data from the original Kaggle source.
