# 07. Saved models

The training script saves each trained model as an `.h5` file. I decided to keep these model files in the public repository because they are only a few megabytes each.

The saved models are useful for two reasons. First, they let someone inspect or reuse the trained networks without retraining everything. Second, they make the repository feel closer to a real experiment record rather than only a code template.

The raw dataset is not committed, but the trained models and evaluation outputs are included because they are generated artifacts from this project.
